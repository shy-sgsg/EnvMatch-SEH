# 研究总纲修订审批协议

## 受保护内容

首版 `docs/RESEARCH_CHARTER.md` 提交后，任何正文修改都必须先获得用户明确批准。受保护内容包括研究主题、总体目标、核心科学问题、主要研究内容、总体思路、长期技术路线、成功标准、创新性边界及限制说明。格式修复若会改变上述含义，也视为正文修改。

## 申请流程

1. 暂停依赖拟修改条款的后续实验；发现的反证或风险照常如实记录。
2. 填写 `docs/templates/CHARTER_CHANGE_REQUEST.md`，注明当前总纲提交 SHA。
3. 提供具体证据、建议文本、替代解释、对既有 PCNM/RUSLE/RF 成果和当前分析的影响及不改的代价。
4. 明确标记 `CHANGE PROPOSAL — USER APPROVAL REQUIRED`，提交用户讨论。
5. 只有收到用户对具体建议的明确批准后，才修改总纲。
6. 将获批依据、修改差异和后续同步文档写入决策记录，并以独立 Git 提交保留版本。

用户未批准时，继续遵循当前总纲。若数据明显否定某个假设，不隐瞒证据，也不继续执行已明显失去科学价值的依赖任务；先暂停该任务并提交审查/修改建议。环境变量清理、性能修复、栅格读取和匹配实现等不改变总纲方向的实施层改进，可在记录依据后执行。
