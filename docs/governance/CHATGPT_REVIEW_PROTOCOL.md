# ChatGPT 科研审查协议

ChatGPT 审查必须先读取本次审查指定的 Git 提交中的 `docs/RESEARCH_CHARTER.md`，再审查同一提交中的代码、配置、数据质量报告和研究结果。不能用当前分支的新文件解释历史实验，也不能只检查程序是否运行。

审查材料须声明分析模式。对 `EXPLORATORY_ORACLE`，还须核查 `outcome_guided_selection` 标记、参与筛选的响应指标和目标、候选试验数、筛选前后样本数、未筛选基线、表观最优结果及空间验证结果。测试集不得用于参数、模型或子集选择；高拟合度不得解释为侵蚀的独立贡献、独立实测验证或正式因果证据。Oracle 结果只能写入 `outputs/exploratory_oracle/`。

审查必须覆盖：

### A. 研究方向

- 是否符合总纲目标并推动对应科学问题；
- 阶段是否具有科学价值；
- 是否偏离主题、忽略阶段门或把条件关联误称为因果。

### B. 数据

- 来源、时间、空间支持、变量含义、单位、缺失和异常；
- 栅格对齐、掩膜、数据可比性及模型输入；
- 预测值、独立实测值和空间重复的区别。

### C. 方法

- 方法是否适用于本批数据、假设是否成立；
- 是否有更合适且可解释的替代方案；
- 是否存在泄漏、选择偏差、空间推断或统计实现问题。

### D. 结果

- 数据、计算和图表是否支持文字结论；
- 配置和输入是否能复现；
- 置信区间、样本单位、效应解释和替代解释是否充分。

### E. 长期价值

- 当前路线是否值得继续；
- 是否有新科学问题或总纲修改必要；
- 下一步和停止条件是否合理。

审查意见需区分事实、推断和建议，指出具体文件/表/图/统计量。阶段任务完成或测试通过不等于方向正确。若建议改变总纲正文，必须标记 `CHANGE PROPOSAL — USER APPROVAL REQUIRED`；未获用户批准前不得实施。

完整审查材料使用 `docs/templates/CHATGPT_REVIEW_REQUEST.md`。
