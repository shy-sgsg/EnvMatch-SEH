# 全项目学术报告扩写设计

## 目的与读者

将现有温县土壤侵蚀—土壤健康报告修订为面向学术读者的系统研究报告。读者应能沿着研究问题、数据与方法、实证结果、空间机制和研究含义完整理解项目，而不必依赖阶段日志或口语化解释。

## 目标

- 以现有已保存的结果为依据，将两章正文及图件解释扩展至不少于50,000个汉字；篇幅统计口径在报告中明确。
- 正文按论文结构展开：研究背景与理论问题、研究区及数据、变量构造和分析方法、结果、讨论、结论。
- 正文选取能够支撑主线的核心图；附录按研究阶段组织项目级图集，对至少100幅可用图逐幅说明研究问题、读图方式及其结果含义，并提供清晰索引。篇幅按两章正文与逐图解释的汉字数合计，不计标题、表格内容和参考文献。
- 全文CEC图件和数值使用现行正确数据，图中指标名称统一写作“CEC”。过时CEC图件须以现行结果替换或从新报告与新图集中排除；占位图、重复呈现和不能支持正文结论的图不作为实证图。
- 采用正式学术中文，细化方法、结果的量化解释及不同分析模块之间的逻辑联系；删除重复辩解、项目过程叙述、幼儿化类比和泛化的免责声明。

## 不在本次范围

- 不重跑 Phase F–K 模型，不改写研究总纲，不覆盖或删除历史阶段结果。
- 不添加没有已保存数据支持的新统计结论，不把探索性条件关联改写为因果结论。
- 不删除论文必要的数据与方法说明；只把来源、分析单位、估计口径和适用范围压缩为规范且与结论直接相关的表述，避免反复强调审计过程或模型缺陷。

## 证据来源与CEC解释

- 主分析暴露为20年平均实际侵蚀。除CEC外，使用Phase K按该暴露整理的已保存结果；涉及CEC的直接统计和图件使用Phase I校正重分析及Phase L对应源表。早期CEC结果视为已被替代，不进入新正文或图集。
- 当前校正定义为 `Erosion = Aa_20yr/max(Aa_20yr) + Aa_2020/max(Aa_2020)`，两项最大值取完整对齐栅格的全域最大值；`CEC_corrected = (CEC - 20 × Erosion)/2.9 + 18`。由于侵蚀项明确进入CEC构造，CEC与侵蚀的关系应作为该复原公式下的结果说明，不能表述成独立测得的自然侵蚀效应。正文在变量定义和CEC结果解释处准确说明一次，不扩展为重复的防御段落。
- SHI沿用当前项目提供的 `SHI_candidate`。已有按章节草稿重建的指数未能复现该图层，因此本轮不以重建指数替代，也不声称SHI已随CEC更正重新计算；涉及SHI时按既有复合指数结果报告。
- 全部结果属于 `EXPLORATORY_ORACLE` 已保存分析。报告沿用相应统计对象与模型结果，不把探索性关联改写为正式因果结论；不重复项目日志和内部审计流程。

## 编写方案与取舍

1. **将全部图直接放入正文。** 图文一体，但连续正文会被大量图件切断，章节主线难以保持。
2. **正文集中论证核心结果，附录逐图解释完整项目图集。** 既保持学术论文结构，也满足项目级图件覆盖和逐图说明需求。**用户已选择此方案。**
3. **仅扩写现有20幅核心图。** 篇章更紧凑，但无法回应项目已有100余幅图件缺少解释的问题。

## 交付结构

第一章阐述研究问题、理论框架、研究区与数据、变量和模型体系；第二章按总体关系、环境匹配、非线性响应、分组异质性、局部空间格局、路径分析和综合讨论展开；附录提供图件分阶段索引、逐图学术解读、主要统计表与术语表。Markdown为统一文本来源，并更新LaTeX、PDF、DOCX及离线HTML图集。

## 留给实施者的决定

依据现有阶段结果、图件说明和CEC版本记录决定每幅图的纳入位置；优先保留具有独立研究问题或补充解释价值的图，合并纯展示重复。新增文献引用须使用可核验的学术来源。所有数值应对应已保存结果；必要的方法边界在方法或讨论中一次性准确说明。
