# Phase J 综合技术报告

## 1. 研究问题与分析框架

Phase J将Phase F–I的匹配、全域响应、环境异质性、GWR/MGWR与压力分区结果综合，并在当前CEC数据基础上开展探索性路径模型。分析目标是区分全域像元关系、环境匹配端点和配对差值的不同统计单位，评估加入环境和空间控制后侵蚀路径的变化，再与局部空间关联和环境候选区对照。该阶段按项目授权在EXPLORATORY_ORACLE模式执行，健康结局参与候选聚合与解释，所有新输出均记录`outcome_guided_selection=true`。

## 2. 数据和CEC审计

环境侵蚀表与健康表各392,527行，cell_id唯一且集合完全相同；行列、投影坐标逐项一致。CEC有效值387,448个，范围16.726—26.837。使用完整对齐Aa表面的全域最大值143.00503540039062和48.76557540893555，按公式 `(CEC_old−20×(Aa_20yr/M20+Aa_2020/M2020))/2.9+18` 复算，当前CEC对有效行的最大误差为0。环境与健康有效标记相交为293,074行；另有71行虽环境总栈标记为无效，但本分析所需暴露、健康和环境变量均有有限值，只缺未进入模型的辅助近邻侵蚀字段，因此按本分析变量完整性纳入293,145个核心案例。端点健康值按cell_id回连当前健康表，避免使用旧CEC缓存。CEC公式内含侵蚀暴露，是重要的代数耦合风险。SHI原始公式、八项指标方向、适宜范围隶属度函数与权重均未找到可核验来源；因此保留原始指标符号和SHI预测面，不构造第二套健康方向统一分值。

## 3. 人群与统计单位

完整像元和主要环境变量完整案例分别提供较宽基线与核心控制模型样本；240 m汇总复现既有7,387单元、293,633个支撑像元，侵蚀与SHI汇总值复现误差为0。该汇总的CEC和2020年侵蚀量在162个单元内合计缺少487个像元支持，AN和pH各缺1个支持像元，均值按每个变量自己的有效像元计算。历史匹配端点版含181,794个端点；后续候选配对版含111,289对及222,578个唯一端点，二者仅共享133,533个端点。两版本参数不同：前者为环境卡尺0.35、地理半径1,000 m、侵蚀百分位差至少0.50；后者为0.75、500 m、土类内8组、侵蚀百分位差至少0.30。正侵蚀样本、零—正配对与土类—地形湿度分组分别作为补充总体。栅格像元为随机森林预测面，不等于同等数量的独立实测。

## 4. 指标和模型定义

暴露为log1p(Aa_20yr)，配对差值为高侵蚀端减低侵蚀端的log1p(Aa)差。物理复合值=(标准化SW−标准化BD)/2；化学复合值=(标准化OM+标准化AN)/2；生物活动=(标准化MBC+标准化RESP)/2。RESP保留原始数值方向，复合值名称使用“生物活动”，不将其解释为单调健康评分。CEC、pH单独建模；CEC不纳入主化学复合值。S1为侵蚀分别关联三维度，S2加入三个维度预测SHI并保留侵蚀直接路径，S3删除侵蚀至SHI的直接路径，S4为侵蚀指向物理维度、物理指向化学维度、化学和物理指向生物活动的有限链式结构，并允许侵蚀关联各维度及直接关联SHI；S5分析单项响应，S6分开估计侵蚀发生与正侵蚀强度。M0为无控制，M1为高程、TWI、NDVI、地表温度和土类，M2为地形与植被—温度PC以及土类，M3为M1加空间坐标多项式。

分段路径回归使用标准化OLS和5 km空间块聚类协方差；无效协方差方差不形成置信区间。成熟lavaan CB-SEM在D1–D4总体拟合S1–S3和M0–M3。拟合指数使用常规ML独立观测假设，不含空间稳健校正；空间块协方差仅用于分段路径回归。形成性Mode-B PLS在D1–D4总体比较S1–S3和M0–M3，共176条内生方程；S1估计三个健康维度，S2/S3增加SHI且分别保留/删除侵蚀直达路径。M1–M3控制作为固定单指标构念，同一总体内采用共同样本。项目内权重迭代没有bootstrap区间或空间稳健推断。自定义协方差路径近似作为方法敏感性保留，不计作成熟CB-SEM。所有结果仍属探索性预测面条件关联，不能替代独立实测验证。

GWR指地理加权回归，用邻近样本估计随地点变化的局部关系；MGWR允许不同环境变量使用不同空间带宽。各模型代号与控制组合定义见本报告术语表。

## 5. 结果概要

共同环境完整像元的核心环境控制模型中，侵蚀与物理、化学、生物活动复合维度的标准化条件路径分别为 -0.389、-0.251、-0.066。保留三个维度与侵蚀直接路径的SHI模型中，直接路径为 -0.113，SHI方程R²=0.601，在维度路径之外加入侵蚀的ΔR²=0.0079。完整参数见结果表和附录图；路径是条件关联分解，不是因果中介。

不同土类×TWI组的核心环境控制维度斜率见表。最负估计来自 42 脱潮土 q1 物理维度: β=-0.478; 27 潮土 q1 物理维度: β=-0.455; 27 潮土 q4 物理维度: β=-0.401。这些组来自响应参与比较的结果导向探索，不构成预设分组的独立检验。

## 6. 模型比较和路径解释

在相同样本和SHI路径结构的比较中，加入空间坐标趋势的方案表观R²最高（0.651）；空间趋势更能重建预测面的空间纹理，不能据此认定侵蚀作用更强。不控制环境的方案ΔR²最大（0.017，直接β=−0.157），但未扣除环境差异。核心环境控制方案（R²=0.601、ΔR²=0.0079、直接β=−0.113）较便于解释，不能称为拟合冠军或因果模型。ΔR²是模型内条件预测增量，不是因果贡献。路径总效应/间接效应为条件路径系数乘积，未计算区间，且维度与SHI共享构造信息。PLS外权与路径系数作描述性呈现；CB拟合指标是自定义协方差近似的朴素独立样本描述量，不是空间稳健或成熟软件拟合结果。模型排序限制在相同统计总体、因变量和结构内。

## 7. 既有全域与空间证据

全域Spearman关联为SW -0.584、SHI -0.469、OM -0.415。第二阶段配对差值ρ为SHI -0.144、OM -0.115、SW -0.272；二者统计单位和目标不同，不能把数值差异解释为匹配后的衰减。图B仅显示SHI、OM、SW的局部关系，不含CEC；九项健康结局的GWR加权汇总系数见 `spatial_synthesis/corrected_nine_outcome_gwr_weighted_summary.csv`。标准MGWR在770个空间均衡单元上SHI、OM、SW的R²为0.869、0.696、0.822。OM、SW的MGWR带宽触及上界，不能外推为精确作用半径。

T1高侵蚀—强负向响应候选区含623个240 m单元，面积等价18.882 km²，平均侵蚀量15.670，SHI均值0.549，局部GWRβ中位−0.567。该结果导向空间候选适合作为现场核查位置，不是已经验证的工程治理区。环境特征应结合土类、灌排、坡面和现场检测共同解释。

## 8. 关键结论、限制和后续

目前可以支持的表述是：当前预测栅格显示侵蚀与部分健康指标存在全域和局部负向关联，所选配对版本的端点差值也呈负向关联；不同统计单位的相关数值不用于推断匹配造成的效应衰减。路径系数取决于总体和控制结构。局部系数与压力区揭示空间差异候选，不是经外部验证的因果热点。CEC路径受代数公式耦合，SHI定义尚未溯源，预测面像元不等于独立样点，结果导向候选筛选带来选择偏差；常规CB-SEM拟合指标未处理空间依赖，5 km聚类也不替代空间独立样本外验证。本阶段未重跑PCNM；后续应保留既有PCNM结果作专门对照，并确认SHI构造和CEC训练数据。成熟lavaan CB-SEM已完成代表结构比较，但不构成因果或独立验证。
