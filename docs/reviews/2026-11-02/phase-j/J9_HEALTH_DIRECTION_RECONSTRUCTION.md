## 文档中的评分规则

S 型函数：`x≤a` 时 μ=0.1；`a<x<b` 时 μ=0.1+0.9×(x−a)/(b−a)；`x≥b` 时 μ=1。

反 S 型函数：`x≤a` 时 μ=1；`a<x<b` 时 μ=0.1+0.9×(b−x)/(b−a)；`x≥b` 时 μ=0.1。

pH 适宜型函数：`x≤a1` 或 `x≥a2` 时 μ=0.1；`a1<x<b1` 从0.1线性升至1；`b1≤x≤b2` 时 μ=1；`b2<x<a2` 从1线性降至0.1。

| 指标 | 文档方向 / 函数 | 参数 | 组合权重 |
|---|---|---|---:|
| AN | 正向 / S型 | a=60，b=120 | 0.171195 |
| OM | 正向 / S型 | a=15，b=40 | 0.142225 |
| CEC | 正向 / S型 | a=10，b=20 | 0.106082 |
| pH | 适宜型 / 抛物线型 | a1=5.5，b1=6.5，b2=7.5，a2=8.5 | 0.087996 |
| SW | 正向 / S型 | a=10，b=15 | 0.113752 |
| BD | 负向 / 反S型 | a=1.15，b=1.5 | 0.109172 |
| MBC | 正向 / S型 | a=100，b=300 | 0.162241 |
| RESP | 正向 / S型 | a=100，b=1000 | 0.107337 |

上述权重和为1。物理、化学、生物维度分别由 SW+BD、OM+AN+CEC+pH、MBC+RESP 构成。方向评分维度为成员隶属度的等权平均；原始值维度则先在同一共同样本内对每项原始指标做 Z 标准化，再对维度成员等权平均。整体方向评分 SHI 为八项隶属度的文档组合权重加权和。

## 结果

分析使用 Phase J r10 的 D1 共同环境完整像元，n=293,145，统计单位为30 m随机森林预测像元；Aa暴露为 `log1p(Aa_20yr)`。条件 OLS 控制高程、TWI、NDVI、LST和土类，标准误按35个5 km空间块聚类。结果是探索性预测面关联，不是独立样点推断或因果估计。

| 指标 | 原始值 β | 方向评分 β | 说明 |
|---|---:|---:|---|
| SW | −0.483 | −0.459 | 方向评分仍为负向 |
| BD | −0.117 | +0.108 | 反S型转换后方向翻转；正值表示健康评分较高 |
| OM | −0.325 | −0.194 | 评分转换后负向关联减弱 |
| AN | −0.052 | −0.056 | 两体系方向接近 |
| CEC | −0.312 | −0.010 | 原始值按含 Aa 的公式恢复；方向评分几乎完全饱和，不解释其系数 |
| pH | −0.004 | +0.004 | 按适宜区间评分；两项控制线性系数均接近0 |
| MBC | +0.003 | +0.003 | 两体系均接近0 |
| RESP | −0.132 | −0.134 | 两体系方向接近 |

| 健康维度 / 综合指数 | 原始值 β | 方向评分 β |
|---|---:|---:|
| 物理维度 | −0.340 | −0.367 |
| 化学维度 | −0.317 | −0.095 |
| 生物维度 | −0.066 | −0.103 |
| 文档权重 SHI | — | −0.288 |
| 既有 SHI_candidate | — | −0.289 |

按文档规则计算的 SHI 与既有栅格在384,211个共同像元上的 Pearson r=0.730、Spearman ρ=0.679、RMSE=0.118、MAE=0.105；既有 SHI 均值比重算值高0.105。新重算值范围0.285–0.673、均值0.505；既有 SHI_candidate 范围0.433–0.775、均值0.610。中等相关不等于公式复现。

CEC 的方向分数在387,448个有效像元中有387,440个达到最大值1（99.998%）。因此，虽然公式和参数已按来源忠实重建，该 CEC 评分在当前栅格上几乎没有空间变异，不能将其回归系数当作有信息的结果；需要核实阈值是否适配当前 CEC 单位和校正后数值范围。pH 在适宜区间右侧的像元占主导，因此原始 pH 与方向评分的秩相关符号相反；这不代表单一线性系数可以概括 pH 健康响应。
