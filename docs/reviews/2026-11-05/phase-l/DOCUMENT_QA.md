# 文档生成与排版核对

- Markdown、LaTeX、PDF和DOCX均由同一份报告正文生成。
- PDF：XeLaTeX生成，A4纸，42页；42页均以低分辨率页面图接触表检查了标题、表格、图件、页眉页脚、截断和空白异常。中文、β和ρ字符渲染正常。
- DOCX：已读取并核对OOXML结构，A4页面、四边2.1厘米页边距、15张表、20个内嵌图片、两章标题及全部正文段落均存在；图像宽度受页面版心限制。Pandoc往返提取保留20张图片及约36,530个汉字。
- DOCX未能在当前环境进行页面级目视渲染：项目提供的`render_docx.py`缺少Python包`pdf2image`，系统也未安装LibreOffice/soffice。Word结构和嵌入资源检查已完成；需要在有Word或LibreOffice的环境打开后，才能最终查看实际分页效果。
- 图像引用检查：20处引用均存在；图表目录为20幅图、15张表。CEC在报告中统一标作CEC；未包含旧CEC公式或校正前值说明。
