# 技术摘要

## 本阶段产出

- 将项目既有F–K分析材料整理成两章的全项目中文详报；只使用20年平均实际侵蚀作为报告主情景。
- 完成20幅无重复图和15张表；新增10幅解释图，均依据已保存单期结果表绘制，不重新拟合模型。
- 同一正文生成Markdown、LaTeX、PDF和DOCX；提供图表索引、证据交叉索引、章节提纲、图集和篇幅核对表。
- 本阶段是报告整理和制版，不是新一轮模型搜索或数据重算。现有SHI与CEC输入按项目当前结果使用；报告中指标名统一写作CEC。

## 主要结果

全域Spearman秩相关显示，SW约−0.584、SHI约−0.469、OM约−0.415；RESP、AN、BD、MBC和pH为较弱负向，CEC约+0.168。当前111,289对匹配候选中，SW、SHI、OM配对差值相关约−0.272、−0.144、−0.115。两类结果统计单位不同，不能相减解释为匹配造成的衰减。

在核心环境控制路径模型中，侵蚀到SHI的标准化条件路径约−0.113，模型R²约0.601，加入侵蚀后的条件ΔR²约0.0079。35个5公里空间块用于稳健区间。空间局部结果整体偏负，但GWR与MGWR对地点强弱排序不完全一致。所有结果来自预测栅格或其派生统计，不能替代独立田间测量，也不构成因果证明。

## 解释边界

项目本轮结果属于授权的结果导向探索；结果用于形成后续假设。像元、匹配对、240米局部单元、770个空间均衡点和5公里空间块是不同单位。低侵蚀折点、环境组及候选区仅作敏感性或调查线索；PCNM未重跑，正式独立验证仍待后续工作。
