# 技术摘要

## 本阶段产出

- 将项目既有分析整理为两章全项目学术报告，以20年平均实际侵蚀作为主线，讲清数据、方法、结果和下一步验证之间的关系。
- 构建“全域关联—环境匹配—非线性响应—局部空间模型—环境控制路径”的多尺度分析叙事，突出每种方法解决的问题及其互补关系。
- 完成20幅图和15张表；重点CEC图件从当前CEC重分析源表更新，图中统一标注为“CEC”。
- 同一正文提供Markdown、LaTeX、PDF和Word版本，并配套两章拆分稿、离线图集、图表目录、证据交叉索引、详细提纲和篇幅统计。
- 本阶段集中提升报告的数据一致性、方法解释力和审查可追溯性；不新增模型搜索。

## 主要结果

全域Spearman显示，SW为−0.584、SHI为−0.469、OM为−0.415，是九项健康结果中最突出的三项负向关联；CEC为−0.286。匹配候选有111,289对，SW、SHI、OM的配对差值相关为−0.272、−0.144、−0.115，CEC为−0.100。CEC在全域、匹配和局部三个尺度均保持负向，局部系数中位数为−0.152，96.7%的局部估计为负。

核心环境控制路径中，侵蚀到SHI的标准化条件路径为−0.113，模型R²为0.601，加入侵蚀后的条件ΔR²为0.0079。局部空间模型、GAM和空间变系数GAM进一步展示了重点结局的非线性与地理差异。全项目报告将这些结果整合为一条从总体格局到局部定位、再到下一步实测设计的证据链。

## 研究价值与后续验证

本阶段的主要方法价值在于跨尺度衔接：全域统计提供基准，匹配差值增加环境可比性，非线性模型刻画响应形状，局部模型呈现空间变化，路径模型整合多变量条件关系。九项结局并列呈现，也使SW、SHI、OM的突出信号与其他指标的不同表现都能被看见。

当前证据来自预测栅格和已有模型结果，适合形成明确的实地验证假设。下一步应预先锁定主要结局和空间验证方案，补充独立土样及农事管理资料，并在不同土类、地形和候选区域开展分层采样。既有PCNM结果保留待用，待分析对象与支持尺度对齐后再作定量比较。
