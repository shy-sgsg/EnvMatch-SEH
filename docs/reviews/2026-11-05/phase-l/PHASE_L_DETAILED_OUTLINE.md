# 详细报告章节提纲

正文分为两章，按“先理解研究怎样做，再理解结果能说到哪里”的顺序展开。

- **第一章 研究问题与分析路径：数据怎样变成可比较的证据**
  - 1.1 从一个直观问题开始
  - 1.2 研究区、栅格与样本的意思
  - 1.3 为什么先检查数据和位置
  - 1.4 从正式研究设计到授权的探索
  - 1.5 先找环境相近的对象：匹配怎样做
  - 1.6 侵蚀分布、零值和为什么不轻易删数据
  - 1.7 总体相关、配对差值和曲线分别回答什么
  - 1.8 环境组与异质性：平均关系可能遮住什么
  - 1.9 局部空间模型：从全县平均走向地图上的每个区域
  - 1.10 路径模型：多项结果怎样放到同一张关系图
    - 1.10.1 为什么同一片地的很多像元仍不等于很多独立证据
    - 1.10.2 为什么比较多种模型，却不选最高分当答案
    - 1.10.3 预测地图和独立实测之间的距离
    - 1.10.4 环境变量相似不等于全部背景相同
    - 1.10.5 结构路径的模型假设也需要读者看见
    - 1.10.6 为什么最后整理成单期结果包
    - 1.10.7 环境变量筛选与分组为什么不能只看相关系数
    - 1.10.8 表观拟合、不确定区间与空间测试的区别
    - 1.10.9 如何读图：每张图都要先看它的横纵轴和对象
    - 1.10.10 项目材料怎样保存，为什么需要固定版本
    - 1.10.11 从数据来源到结论，需要经过哪些核对
    - 1.10.12 相关、回归、曲线和空间图各自回答什么
    - 1.10.13 多次尝试怎样如实写进报告
    - 1.10.14 从栅格输入到图集交付的完整工作顺序
    - 1.10.15 用日常例子理解“像元多”和“证据多”的区别
  - 1.11 研究过程的阶段衔接与证据边界
- **第二章 结果、解释和下一步：目前看到什么、还能相信到哪一步**
  - 2.1 先说明结果证据的等级
  - 2.2 总体关系：哪些指标最稳定地呈负向
    - 2.2.1 从匹配试验到本报告：每段工作增加了什么
  - 2.3 环境匹配：相似背景下关系是否仍然存在
  - 2.4 关系是不是直线：曲线能提供什么
    - 2.4.1 零值和低值的敏感性：为什么不把折点当作天然分界
  - 2.5 环境分组：不同背景下是否有不同斜率
  - 2.6 局部空间差异：哪些地方的估计更负
  - 2.7 路径分析：控制环境以后SHI的关系还剩多少
  - 2.8 现场核查候选区：帮助抽样，不是风险边界
  - 2.9 把样本和证据链画清楚
  - 2.10 用五个问题归纳当前发现
  - 2.11 结果支持什么，不支持什么
    - 2.11.1 把现有发现按证据层级放在一起
    - 2.11.2 结果方向不一致时，应保留差异并解释它
    - 2.11.3 报告结论时避免五种常见误读
  - 2.12 下一步：怎样把地图线索转成可靠的田间问题
  - 2.13 面向普通读者的总结
  - 2.14 读完整份报告后，怎样把专业词换成日常语言
