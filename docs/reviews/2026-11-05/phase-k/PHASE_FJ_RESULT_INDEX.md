## 阅读边界

全域像元、匹配端点、匹配差值、240米汇总单元和空间块是不同统计单位；其相关或回归系数不能直接相减。所有新整合内容属于探索性条件关联，空间预测像元不等于独立实测样点。指标方向与处理均沿用用户提供的SHI和CEC图层；图题统一写“SHI”和“CEC”。
