# 七分钟汇报稿

大家好，今天我汇报的是温县耕地中，20年平均土壤侵蚀与土壤健康之间的空间关系。

我们要回答的不是一个简单的“侵蚀高、健康是不是低”。因为在农田里，坡度、地形、土壤类型、温度、植被和灌溉条件都可能同时影响侵蚀和土壤健康。若两类像元的环境本来就不同，普通相关很难判断关系来自哪里。所以研究先对照环境相近的位置，再从全域、非线性和空间模型几个角度检查结果。

数据以30米栅格表示。我们直接使用现有的20年平均实际侵蚀、土壤健康指数SHI、八项土壤指标以及环境图层。这里需要强调，栅格像元是地图位置，不等于相同数量的独立土壤样本；相邻像元彼此相似，统计时必须考虑空间依赖。侵蚀相关主要用log(1+Aa_20yr)，这样零值仍然保留，特别大的侵蚀值影响也不会过度放大。

先看全域结果。九项健康结局中，土壤含水量的Spearman相关约为负0.584，SHI约为负0.469，有机质约为负0.415，是关系最清楚的三项。其余几项大多是较弱负相关，CEC则呈较弱正相关。这告诉我们，不能说所有土壤指标都会跟着侵蚀一起变差，不同指标回应的过程不一样。

再看环境匹配。后续一套匹配形成了111,289对高、低侵蚀端。我们比较每对里面的侵蚀差和健康差，发现土壤含水量、SHI和有机质的配对差值相关仍然是负的，分别约负0.272、负0.144和负0.115。也就是说，在已观察的环境条件相近的配对里，侵蚀较高的一端仍倾向于有较低的这三项结果。不过这不是因果证明，未记录的耕作、灌溉、施肥和历史土地利用仍可能影响两边。

关系也不是完全直线。GAM平滑曲线显示，SHI、有机质和土壤含水量总体随20年侵蚀上升而下降，但下降速度会变化。20年侵蚀有较多零值，低端分布筛选后，部分关系反而变弱，空间验证也没有一致改善，因此主解释保留全部有效样本，只把低值筛选作为敏感性分析。

接下来是空间结果。局部回归把不同地点周围的关系单独估计。SHI、OM和SW的局部系数中位数大约为负0.222、负0.395和负0.486；其中SHI约99.6%的估计单元系数为负，OM和SW为负的比例接近100%。但这只是符号比例，不是显著比例。不同局部模型虽然大多判断方向为负，却对“哪里最强”的排序意见不完全一样。也就是说，总体方向比较稳定，具体位置还存在模型不确定性。

空间候选区也能帮助安排下一轮调查。T1大约有623个240米单元，面积等价约18.9平方公里，平均侵蚀较高，局部负向关系也较强。T1、T2、T3和T4都只是抽样候选，不能直接当正式风险区或治理边界。最合适的用途是把它们当作分层抽样的地图提示，并在强负向区、高侵蚀对照区和环境对照区都采样。

最后看路径模型。控制核心环境变量后，侵蚀到SHI的标准化路径约为负0.113，模型R²约0.601，而侵蚀本身增加的条件预测量约0.0079。物理维度和化学维度的路径较强，生物活动维度较弱。这表示环境背景解释了很大一部分空间变化；侵蚀仍提供一点额外信息，但不能把这部分说成侵蚀单独造成的比例。

总结来说，目前多种分析都提示土壤含水量、有机质和SHI值得优先实测核查，且关系会随位置和环境改变。我们得到的是空间预测数据中的探索性条件关联，不是因果结论。下一步应在不同候选区开展独立土样和实际侵蚀调查，记录田间管理，并预先锁定分析方案，最后用没有参与本轮筛选的新数据检验这些关系能否重复。
