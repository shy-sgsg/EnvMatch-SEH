# Phase K 阶段总结：20年平均侵蚀单情景

## 研究主线

本轮把项目F–J已有结果整理成一条清楚的证据链，并额外提供一套只使用20年平均实际侵蚀的报告与图件。顺序是：先核对栅格和样本单位，再看环境匹配后差值；随后比较全域关联、平滑响应、环境组差异和局部空间系数；最后使用路径模型归纳环境控制后的关系，并把空间候选区转成后续实测抽样线索。

## 四项核心发现

1. 全域范围内，20年平均侵蚀与土壤含水量、SHI、有机质的Spearman相关最强，分别约−0.584、−0.469、−0.415。CEC方向为较弱正相关（约+0.168），九项指标不应概括为同向变化。
2. 更新的环境匹配候选包含111,289对。配对差值中SW、SHI、OM的秩相关约−0.272、−0.144、−0.115，说明已匹配总体中仍有负向条件关联；这不表示匹配造成了关联衰减或已排除所有混杂。
3. GAM和GWR-LCR共同显示SHI、OM、SW总体偏负，局部强弱会随空间位置变化。局部β负向比例不是显著比例；不同空间模型对“哪里最强”的排序并不完全一致。
4. 控制核心环境变量的路径模型中，20年侵蚀到SHI的标准化路径约−0.113，R²约0.601，侵蚀条件ΔR²约0.0079；侵蚀到物理、化学、生物活动维度约−0.389、−0.251、−0.066。新增预测信息有限，路径不是因果效应。

## 空间候选

强负向候选区包含623个240米单元，面积等价约18.882平方千米，平均侵蚀约15.67、平均SHI约0.549，局部GWR系数中位数约−0.567。另有高侵蚀对照、低侵蚀但SHI偏低对照和环境对照候选。它们只用于设计下一轮实地抽样，不是正式风险图或工程边界。

## 限制和下一步

分析来自空间预测栅格，像元间有空间依赖；部分环境分组、模型候选与区域候选受结果查看影响；环境匹配无法控制未记录的管理因素。GWR、MGWR和局部空间统计的估计尺度不同。既有PCNM结果继续保留，尚未完成预先锁定的跨方法比较。下一步应增加独立土样和田间侵蚀测量，记录耕作、灌溉、施肥和作物信息，并在实测数据上预先固定分析方案。
