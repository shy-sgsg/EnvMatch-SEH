# Phase G 探索性研究报告：环境匹配后的侵蚀—土壤健康关联

> **分析模式：** `EXPLORATORY_ORACLE`，`outcome_guided_selection=true`。本报告描述既有 30 m 健康预测栅格的条件关联与环境异质性，不是因果估计，也不是独立实测验证。

## 1. 研究问题与主要发现

本阶段对应研究总纲 Q1–Q3：环境匹配后侵蚀与健康指标是否相关、关联是否随环境背景变化、九项指标是否呈现不同响应。主要暴露为既有 20 年平均实际侵蚀 `Aa_20yr`，2020 年 `Aa_2020` 为对照。高侵蚀端减低侵蚀端定义健康差值；侵蚀差值使用 `log1p(Aa高)-log1p(Aa低)`。

M4 直接最近邻配对中，20 年平均侵蚀下，SHI、OM、SW 的 Spearman ρ分别为 -0.128、-0.114、-0.192；AN 与 MBC 接近零，CEC 为正向 0.060。2020 年结果的秩相关方向与 20 年均值不同且整体接近零。九项指标方向并不一致，不能概括为“侵蚀普遍降低土壤健康”。空间块相关区间较宽，原始检验 P 值不能消除空间依赖。

## 2. 数据、设计与统计解释

环境表与健康表各有 392,527 行，按 `cell_id` 一对一连接；主土类为 26、27、42。两项 Aa 均沿用预计算值，未重算或验证 RUSLE 因子乘积。预测栅格像元数不等于独立实测样点量。Aa 单位和精确时间构造沿用既有资料登记，未在本轮推断。

土壤类型编码按原始类别属性表对应为：**26—冲积土，27—潮土，42—脱潮土**；环境分组地图和图例均采用“代码＋名称”。

配对复用 Phase F M3（土类内 V5 高程/地表温度 K 均值 k=6）和 M4（土类内直接最近邻）；环境卡尺 0.35、地理距离上限 1,000 m、组内侵蚀百分位差 0.50、无重复使用。配对斜率及平均差区间按 5 km 配对中点空间块重抽样；Spearman 区间用空间块数作有效样本量的 Fisher-z 近似。Wilcoxon、Spearman/Kendall 的原始 P 值仅作描述。

Phase G 复用上游 Oracle 中 10,616 条实验记录。像元预测模型和配对差值模型分开排名；前者包含环境变量，其高表观 R²不能解释成侵蚀的独立贡献。非线性模型方向按存档曲线在共同暴露范围的变化判断，无法判定时保留为“未知”。环境分组包括土类、V5 K 均值、Ward 聚类和多个环境变量分位组。

## 3. 空间验证与范围校正

空间候选以验证块选模后再计算测试块表现；另报告 Phase F 十次 5 km M3/M4 配对测试。由于此前 Oracle 搜索反复使用全域数据，这些划分是内部空间诊断，而非未触碰外部验证。补充分析按候选 ID 识别主要耕地土类，排除 18 条明确属于非主要耕地土类的模型结果；SoilType 85 为水体。修正后的候选榜单见 `tables/completion/candidate_scope_reconciliation.csv` 和 `tables/completion/in_scope_pixel_model_leaderboard.csv`。

验证集选出的像元模型测试 R²因指标而异：AN 0.436、BD 0.332、CEC 0.361、MBC 0.355、OM 0.339、RESP 0.421、SHI 0.470、SW 0.570、pH -0.023。像元与配对测试指标分开保存；配对差值模型的十种子测试表现中位数总体接近零。空间测试结果不能回过头用于挑选模型或样本。

## 4. 环境异质性与 Oracle 选择

环境组内关联、环境画像和复合排序分别保存在 `tables/environment_group_associations.csv`、`tables/environment_group_statistics.csv` 和 `tables/environment_group_leaderboard.csv`。补充分析对 M4/Aa_20yr 中各指标负斜率最强的环境组绘制空间块聚类稳健区间。组的定义主要来自环境变量，但挑选“最负”组读取了健康结局，属于 Oracle 结果导向筛选。单变量分位组也可能残留其他环境差异；不能把组标签解释为治理机制。

## 5. 结论边界与下一阶段

- 九项健康指标的差值与秩相关方向不一致；应逐指标报告，避免“普遍降低”的概括。
- 统计单位包括像元、匹配对、空间块和独立实测样点，彼此不能混为一谈。
- 全域 Oracle 结果导向筛选造成选择偏差；高表观 R²和最强组不等于独立验证证据。
- 本阶段未修改研究总纲；既有 PCNM 结果继续保留，不在此处重跑或替代。
- 在更强推断前，应先核实 Aa 与健康栅格来源、单位和时间定义，并取得研究者/ChatGPT 对方法的复核意见。
