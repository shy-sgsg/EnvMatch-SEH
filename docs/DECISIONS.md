# 方法与工程决策

## 2026-10-24：第一阶段初始决策

1. **保留 PCNM 成果。** PCNM 作为既有对照结果导入；本项目不重跑，也不根据新增结果覆盖既有结论。
2. **主匹配变量与结果隔离。** 主距离排除 R/K/LS/C/P，并排除 SHI 和八项健康指标。健康变量只在匹配方案确定后进入分析。
3. **环境组候选。** 初始连续变量 Elevation、Cur、TWI、LST；土壤类型精确分层；k 候选为 6、8、10、12。最终选择只依据环境质量、空间覆盖和解释性。
4. **侵蚀暴露。** 实际 Aa 为主、Ap 为补充；使用 `log1p(Aa)`，保留零值并先检查 C 因子来源。
5. **匹配空间半径。** 300、500、1000 m 为候选诊断值，不预先宣称最终阈值。
6. **环境依赖。** 当前环境已有 rasterio，可用 GeoTIFF 与栅格掩膜；避免引入不必要的 geopandas 依赖。矢量读取能力仅在实际接口需要时增加。
7. **版本与运行可追溯。** 当前 Python 3.13.5 可满足 Python 3.11+ 项目要求；每次运行保存配置与软件版本。未提供数据前不固定研究结论。
8. **仓库状态。** 用户明确提供并授权目标远端 `git@github.com:shy-sgsg/EnvMatch-SEH.git`。当前工作区的 `.git` 是只读空目录，且 GitHub 远端访问失败；在取得可写 checkout 和远端访问前，不创建无法证明与远端历史相连的提交。恢复后先核对分支和历史，再提交、推送并记录提交 SHA。
