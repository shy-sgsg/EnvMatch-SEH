## 2026-10-24：第一阶段初始决策

1. **保留 PCNM 成果。** PCNM 作为既有对照结果导入；本项目不重跑，也不根据新增结果覆盖既有结论。
2. **主匹配变量与结果隔离。** 主距离排除 R/K/LS/C/P，并排除 SHI 和八项健康指标。健康变量只在匹配方案确定后进入分析。
3. **环境组候选。** 初始连续变量 Elevation、Cur、TWI、LST；土壤类型精确分层；k 候选为 6、8、10、12。最终选择只依据环境质量、空间覆盖和解释性。
4. **侵蚀暴露。** 实际 Aa 为主、Ap 为补充；使用 `log1p(Aa)`，保留零值并先检查 C 因子来源。
5. **匹配空间半径。** 300、500、1000 m 为候选诊断值，不预先宣称最终阈值。
6. **环境依赖。** 当前环境已有 rasterio，可用 GeoTIFF 与栅格掩膜；避免引入不必要的 geopandas 依赖。矢量读取能力仅在实际接口需要时增加。
7. **版本与运行可追溯。** 当前 Python 3.13.5 可满足 Python 3.11+ 项目要求；每次运行保存配置与软件版本。未提供数据前不固定研究结论。
8. **仓库状态（2026-10-24 初始记录）。** 用户明确提供并授权目标远端 `git@github.com:shy-sgsg/EnvMatch-SEH.git`。当日初始目录的 `.git` 为空且 GitHub 远端访问失败，因此当时没有创建与远端历史无关的仓库。

## 2026-10-25：耕地双时期侵蚀与 G2–G4 实证可行性

1. **暴露时间定义。** 用户确认 `实际侵蚀_wx.tif` 为 20 年平均 `Aa_20yr`，主分析使用该层；`2020年A` 为单年 `Aa_2020`，作为预先指定的时间比较。两层的单位、精确年份范围和计算/平均定义仍以缺失元数据处理，不自行推断。
2. **分析网格和耕地编码。** 采用 `SHI/温县耕地.tif` 的有效值 12 作为耕地，并以该 30 m、EPSG:32649 栅格为目标模板。面积平均为侵蚀主对齐方法，最近邻为敏感性；分类层最近邻、连续层双线性。旧面积 347.877 km² 与掩膜面积 353.2743 km² 的 1.55% 差异保留，不人为裁切。
3. **G3 主候选向量。** Elevation、Cur、TWI、LST 连续标准化；SoilType 26、27、42 分层，水体 85 排除。其他协变量只做来源/缺失筛查，不依据健康结果筛选或调权。
4. **G4 候选设置。** 每种土类分别测试 6、8、10、12 个环境组；500 m 下比较四种分组数，并以 k=8 对照 300/1000 m。基线为标准化欧氏环境距离 0.5、组内侵蚀百分位秩差 0.25、无重复使用；附环境阈值、秩差及最近邻重采样敏感性。所有参数均是待审查的候选设置，不是锁定方案。
5. **阶段门。** G2/G3 允许在明确限制下开展探索性 G4，但不能据此宣称物理单位已核实；G4 的聚类 silhouette 接近 0 且随机种子稳定性不一，匹配数量和 SMD 不能单独决定最优分组。待 ChatGPT/用户审阅候选质量与数据来源后再决定是否锁定设计。健康面为预测面且来源未完全确认，因此本轮不开展 G5；健康结果不得进入 G4。
6. **不重建 RUSLE。** 延续用户的明确指示，使用已算好的实际侵蚀值；本轮不以 RKLSCP 乘积校验作为阶段门。对 Aa 栅格本身的零值、缺失、范围、网格和时间/单位元数据仍如实报告。
7. **总纲状态。** 本轮只补齐数据和方法证据，不改变研究问题或长期技术路线，`docs/RESEARCH_CHARTER.md` 保持不变。
